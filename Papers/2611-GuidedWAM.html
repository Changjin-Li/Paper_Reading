GuidedWAM: Training Free Energy Guidance for World Action Models in Autonomous Driving

GuidedWAM: Training-Free Energy Guidance for World Action Models in Autonomous Driving

arXiv Preprint·Technical University of Munich, Munich Institute of Robotics and Machine Intelligence (MIRMI)·Xiyan Su , Finn Rasmus Schäfer, Hojun Lim, Frank Diermeyer, Johannes Betz, Markus Lienkamp

Nov 17, 2026

  • world-model
  • flow-matching

Summary

WAM 把驾驶策略与视觉世界模型耦合在同一个生成网络里，训练结束后驾驶目标就冻结了：想加”窄路多留边距""行人周围更大净空""分段限速”这类新目标，只能重新收集监督并重训十亿参数模型。GuidedWAM 把能量引导做成一个训练无关的控制通道：在每个采样步上，用冻结模型的一步干净估计 τ^0​ 评估可微能量，把它的梯度直接加到速度场上；由于梯度只对解析能量求、干净估计被 detach，整条链路只需要对冻结模型做前向。为了让这种 Jacobian-free 形式可用，论文给出三项稳定化措施——噪声水平上的梯形调度窗、逐能量归一化、以首次引导步的速度范数为上界的修正裁剪。在 NAVSIM v2 hard-split 上，用单一的相机可行驶区域能量，三个已公开 WAM 的 EPDMS 提升 +1.8 至 +3.6（三 seed 平均），每步采样耗时增加不到 10%。

Problem & Motivation

  • WAM 的规划目标在训练时被冻结：新目标只能靠”补监督 + 重训”获得，而且每加一个新目标就要重来一次，成本与目标数量线性增长。
  • 采样期的条件化是另一条路，但它通常要求该目标在训练数据里出现过（conditioning 依赖训练时的 label），对”部署时才出现的临时目标”无效。
  • 现成的 guidance 机制（classifier guidance、classifier-free guidance）都需要额外的分类器或无条件分支；能量引导（energy guidance）只需要一个可微目标函数，与模型训练解耦，是更合适的载体。
  • 难点在于：精确的能量引导需要 clean estimate 对 τt​ 的 Jacobian Jt​，而 Jt​ 含网络 Jacobian，等价于每个采样步做一次完整反向传播——对十亿参数视频 WAM 不现实。
  • 因此论文的问题是：能否只靠前向访问，在冻结 WAM 的采样过程中注入新目标，并让它稳定工作？

Method

1. 预备：flow matching 的 score-velocity 对应（§3.1）

  • 动作流 τ∈RT×d（自车轨迹或动作 token 序列）由条件 flow matching 采样器生成：τt​=(1−t)τ0​+tε，ε∼N(0,I)，网络学 vθ​(τt​,t,X)≈E[ε−τ0​∣τt​,X]，采样从 t=1 积分到 t=0。
  • 引导本质是对 score st​=∇τt​​logpt​(τt​∣X) 的修正；在 Gaussian flow matching 路径上 score 与速度可互相换算：
v(τt​,t)=−1−tτt​+tst​(τt​)​
  • 因此一个 score 修正 Δs 进入速度场时要乘上 −t/(1−t)。论文在 score 空间推导、在速度空间实现，因为公开的 WAM 采样器只暴露速度场。

2. 一步干净估计上的能量引导（§3.2）

  • 每个采样步都能得到当前噪声下的后验均值，也就是 clean estimate：
τ^0​(τt​)=τt​−tvθ​(τt​,t,X)≈E[τ0​∣τt​,X]
  • 驾驶目标被写成关于干净轨迹的可微能量 E:RT×d→R（到车道中心线的距离、到可行驶边界的 signed distance、到预测 agent 框的净空等）；实际使用时先把 τ^0​ 解码成带位置与朝向的 waypoint 序列，再在几何量上解析求梯度。
  • 目标分布是对原后验的能量倾斜：
pγ​(τ0​∣X)∝p(τ0​∣X)e−γE(τ0​)
  • 把倾斜写成”以辅助变量 G 为条件”，并令 p(G∣τ0​)∝e−γE(τ0​)，由 Bayes 规则得 p(τ0​∣G,X)=pγ​(τ0​∣X)，于是条件化后的 score 是：
stγ​(τt​)=st​(τt​)+∇τt​​logEp(τ0​∣τt​,X)​[e−γE(τ0​)]
  • 期望不可解，于是用 clean estimate 代替后验平均（与 diffusion posterior sampling 同源），log-expectation 变成 −γE(τ^0​)，链式法则给出：
∇τt​​E(τ^0​(τt​))=Jt⊤​∇τ^0​​E(τ^0​),Jt​=∂τt​∂τ^0​​=I−t∂τt​∂vθ​​
  • 这里做了全文最关键的一步近似：把 Jt​ 换成单位阵，只保留能量自身的梯度，并在 detached 的干净估计上求值（manifold-preserving guided diffusion 的做法）。换算回速度空间后得到实际执行的更新：
v′=vθ​+λ(t)∇τ^0​​E(τ^0​),λ∗(t)=γ1−tt​
  • “无需反向传播”是这么来的：干净估计被 detach，唯一被求导的对象是解析能量对一个 T×d 张量的函数；冻结模型每步只前向一次，不保存激活。这也解释了为什么它能直接作用在已发布的 checkpoint 上。
  • 代价同样明确：被删掉的 Jt​ 原本是一个预条件子，把推力投影到局部合理的流形方向上；删掉后修正更容易离开流形，而 canonical 调度 λ∗(t)=γt/(1−t) 在 t→1（clean estimate 最不可靠处）发散。

3. 三项稳定化（§3.3）

  • 梯形调度窗：canonical λ∗ 把最大修正放在高噪声端（t→1），那里 clean estimate 只是未来的粗略平均；常数 λ 则在 t→0 还在推、而那时计划已定。于是把调度截成噪声水平上的梯形窗——中段最大、两侧线性升降：修正只在干净估计变得有信息之后才起作用，末段留给冻结模型把计划拉回流形。
  • 逐能量归一化：不同能量的梯度尺度差异大，所以先按样本归一化再加权，让 λ(t) 独占”总强度”、wk​ 只表达相对重要性：
Δv=k=1∑K​wk​∥∇τ^0​​Ek​(τ^0​)∥2​∇τ^0​​Ek​(τ^0​)​
  • 速度有界修正：修正的幅度相对模型自身速度设上界。若上界按当前速度测，会被”推力把下一步速度抬高、上界随之抬高”的正反馈放大（作者报告早期实验里速度范数涨了数倍、轨迹端点跑出路网一公里以上），所以参考量在第一引导步记录一次后固定：
ρ=∥vθ​(τt​)∥2​,Δv←min(1,λ(t)∥Δv∥2​cρ​)Δv
  • 这样每一步都满足 λ(t)∥Δv∥≤cρ，且比例常数 c 跨模型共享——这是”强度只需按模型标定一次”的机制基础。

4. 能量的构造（§4.2、§4.3）

  • 主实验只用一个合法能量：相机可行驶区域（DA）。它由前视相机回归出的 signed distance field 给出，当车体某个角点距道路边缘小于 0.5 m 时激活，因此对已经安全远离边界的场景几乎不改动（约在 15% 的已通过场景上触发）。
  • 消融里加入两项需要特权信息的能量：DD（waypoint 朝向与车道方向相反则惩罚，相对 barrier 权重 0.06）与 LK（把轨迹吸引到车道中心线）。
  • 三类能量的稀疏性不同：DA、DD 是稀疏事件型，LK 是稠密连续型，这一差异直接导致”全叠加反而更差”（见 Key Results）。

Pipeline

同一个 NAVSIM v2 场景上，原计划（灰）驶出可行驶区域；事后投影（蓝）在违反约束前不动、触发后突然横向折回；能量引导（橙）从第一个去噪步起就沿整条轨迹平滑修正，最终两者都通过可行驶区域门限，但引导版本的相邻帧一致性更好。

  1. 冻结模型前向：在噪声水平 t，采样器把当前动作流 τt​、观测上下文 X（历史帧、ego 状态、导航命令）送进 WAM，得到速度场 vθ​。
  2. 构造干净估计：用 τ^0​=τt​−tvθ​ 得到”模型认为的最终轨迹”，并 detach，切断对网络的求导路径。
  3. 解码并评估能量：把 τ^0​ 解码成 waypoint 的 (x,y,ψ)，在其上解析计算各项能量（DA / DD / LK），得到梯度 ∇τ^0​​Ek​。
  4. 归一化与加权：每个能量的梯度按样本 L2 归一化，再按 wk​ 加权求和，得到总修正方向 Δv。
  5. 调度与裁剪：用梯形窗给出 λ(t)（中段最大、两端线性衰减），再用首步记录的速度范数 ρ 把 λ(t)∥Δv∥ 裁剪到 cρ 以内。
  6. 写入速度场并积分：执行 v′=vθ​+λ(t)Δv，按 Euler 积分更新 τt​，回到第 1 步，直到 t=0。
  7. 输出：末步的干净轨迹直接作为规划结果；整个过程不改任何权重，也不增加反向传播。

Strengths & Weaknesses

Strengths

  • 问题选得实：把”部署期目标会变、但重训成本不可承受”讲成一个具体的控制通道问题，而不是再刷一个 benchmark；能量引导确实是少数只需前向访问就能改行为的机制。
  • 推导链条完整且自洽：从 score-velocity 恒等式 → 能量倾斜 → 辅助变量重写为条件化 → clean estimate 近似 → 删 Jacobian，每一步都写清了近似来源与代价（Jt​ 作为预条件子被删、canonical 调度在 t→1 发散），比”我们加了个梯度项”清楚得多。
  • 稳定化不是凑出来的：梯形窗对应”高噪声端梯度无意义、低噪声端计划已定”，归一化对应”不同能量尺度不可比”，速度上界对应”正反馈放大”——每条都有明确失效模式，Figure 3 还给了抖动率与 ADE/FDE 的量化。
  • 在三个公开 checkpoint 上验证：DriveLaW / DriveWAM / SimWAM 全部冻结、只做前向，这比”自家模型 + 自家引导”更能说明通道的通用性；三个 seed 报告标准差。
  • 诚实地报告了投影更强：Table 2 明确写出投影在 DAC 上更有效、EPDMS 更高，只在舒适度上更差。这种”我们的方法不是最优修复器”的表述很少见，也让”一致性换分数”的取舍变得可信。
  • 开销测量到组件级：0.1 / 1.4 / 1.9 ms 的每步引导耗时对 48 / 16 / 36 ms 的前向，加上 Jacobian 形式的 50.4 / 72.5 ms 对照，把”训练无关”具体化成了可核对的数字。
  • cross-fitting 处理了没有验证集的问题：一半搜参一半评测、交换平均并给 bootstrap 区间，比直接在全 split 上调参再报分要严谨。

Weaknesses

  • 只验证了一种能量、一个 benchmark、一个 split：主表所有增益都来自 camera-based DA，而 DA 恰好与 EPDMS 的 DAC 门限直接对应；换一个与指标无直接耦合的目标（如乘客舒适偏好、分段时间预算）能否同样work没有证据。跨 benchmark（NAVSIM v1 / HUGSIM / 闭环）完全缺失，作者在 Limitations 里也承认。
  • 增益与失败修复是两回事：正文说 DA 引导只清掉 1–3 个百分点的失败合成场景，而 EPDMS 涨 1.8–3.6。EPDMS 的乘性门限意味着少数场景从 0 变正会带来不成比例的分数变化，因此”分数提升”并不等于”驾驶变得更安全”，论文没有给出通过率 / 失败数的绝对统计。
  • 碰撞与方向合规完全没动：NC 与 DDC 在各模型上都在 stock 的 1 分以内，说明这个通道对”最危险的一类失败”无效。作者写得很诚实，但也意味着把它称为”驾驶目标的通用注入机制”目前只覆盖了几何边距这一类目标。
  • 两个数量级的强度差异靠人工标定：DriveWAM 需要 λ=4，另两个只需 0.05；虽然给出了”相对修正占速度比例”这个模型无关单位（1.4% vs 45%），但比例本身仍要靠扫参确定，论文没有给出”不看结果就能估出合适 λ“的方法。cross-fitting 只能证明”选出来的强度可迁移”，不能证明”无需调参”。
  • 梯形的窗口形状基本是手工设计：中段最大、两侧线性，起止位置与斜率都没有消融；Figure 3 显示 λ=128 时梯形窗反而更差（末段权重仍大），说明窗口与强度的耦合没有被处理，实际使用需要联合调两个超参。
  • 能量叠加只是加权和：作者自己指出这无法调和互相矛盾的能量（例如”靠边停车”与”保持车道中心”），并把 STL robustness 列为下一步。这限制了它作为”通用目标注入”的适用范围，而 Table 3 的”全叠加更差”正是这一局限的直接体现。
  • DD 能量权重 0.06 的来源没有交代：这个相对权重明显经过调参，而 DD 单独使用时几乎无效（≤1 分），因此”DA+DD 最优”这一结论对权重的敏感性未知。
  • 确定性 Euler 采样器的前提：所有实验都在确定性积分器上做，随机采样器（SDE / 随机 Euler）下的调度与强度范围未验证；作者在 Limitations 里承认，但这也意味着方法对”换采样器”的鲁棒性未知。
  • 与事后投影的比较只在 DAC 上：Table 2 用的是特权 DA 信息、0.5 m 边距，这一设置对投影天然有利（后验修正可以精确落在约束上），而引导用的是软能量。更公平的比较应是”同样软约束的事后优化”，论文没有做。

Notes

  • 论文定位：不是新的 WAM 架构，而是给冻结 WAM 加一条推理期控制通道。核心 insight 是：只要目标能写成干净轨迹上的可微函数，它的梯度就能在 flow matching 采样中当作 score 修正使用；而”删掉网络 Jacobian、只保留能量梯度”这个近似，把成本从一次反向传播降到可忽略，代价是必须用调度窗 + 归一化 + 速度上界把它按住在流形附近。
  • 可迁移点：
    • “detach clean estimate + 解析能量梯度”是通用的免训练约束注入配方：任何 flow / diffusion 策略（不限于驾驶）都可以用它在推理期加新目标，前提是目标能写成几何量的可微函数。
    • 速度有界修正的参考量必须在首步冻结：按当前速度设上界会形成正反馈，这是把”引导”变成”发散”的常见坑，作者的 ρ 记录一次的做法可以直接复用。
    • 梯形调度窗：高噪声端梯度是多个未来平均、低噪声端计划已定，因此修正应集中在中间噪声段；这一经验对任何在采样器上做外部修正的方法都成立。
    • 用”相对修正占模型速度的比例”做跨模型比较：直接把 λ 在不同模型间比较没有意义（这里差两个数量级），换成相对量后能看出真正的敏感度差异（1.4% vs 45%）。
    • 把 in-sampling 修正与 post-hoc 投影放在同一约束下对比：这是评估”约束注入”类方法最该做的对照，因为投影通常分数更高但一致性更差，只看 EPDMS 会得出错误结论。
  • 待跟进：
    • 用一个与 EPDMS 指标不直接耦合的目标（例如”乘客纵向 jerk 上限”或”与 VRU 的净空下限”）重做实验，检验这套通道是否只对”指标对应的约束”有效。
    • 在随机采样器（SDE / 随机 Euler）上重扫 λ 与梯形窗，确认当前超参是否依赖确定性积分。
    • 把 DA 能量换成”多类目标的 STL robustness”实现组合，检验能否解决 Table 3 中”稠密项稀释稀疏项”的问题。
    • 补一个与”软约束事后优化”的对照（而非硬投影），判断引导的优势有多少来自 in-sampling、多少来自软约束本身。
